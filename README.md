# Robot Limpiador

Este proyecto consiste en la implementación de un agente inteligente para simular un robot limpiador que se mueve entre varios cuadrantes para limpiarlos.

## Funcionalidad

El robot limpiador sigue las siguientes reglas:

- El robot se mueve aleatoriamente entre los cuadrantes.
- Si un cuadrante está sucio, el robot lo limpia.
- Una vez que un cuadrante está limpio, el robot puede pasar a otro cuadrante.

El objetivo del robot es limpiar todos los cuadrantes del área de trabajo.
